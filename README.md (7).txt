# Task 31 - Correlation Analysis

## Overview
This project explores relationships between numerical variables using correlation analysis and data visualization.

## Topics Covered
- Creating and exploring a numerical dataset
- Calculating a correlation matrix using Pandas
- Visualizing correlations with a heatmap
- Creating scatter plots to explore relationships
- Calculating correlations between selected variables
- Identifying strong and weak correlations
- Interpreting correlation results
- Understanding that correlation does not imply causation

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Sample student data containing study hours, marks, sleep hours, and attendance.

## Files Included
- `task31_correlation_analysis.ipynb`
- `README.md`

## Outcome
Learned how to calculate, visualize, and interpret correlations between numerical variables using Python.
